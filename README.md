# tw-koubo-cut：用 Claude 剪中文口播短影音

不開剪輯軟體，把一支中文直式口播影片丟給 Claude，自動剪掉重講與停頓、降噪、加字幕（強調字換色）、第 0 幀標題、b-roll、音效、原創配樂，輸出 1080x1920 成品和 srt 字幕檔。

## 你需要什麼
1. Claude 付費方案（Pro 以上，依 Anthropic 支援文章；方案內容請以官網為準）
2. 在 Settings（設定） → Capabilities（功能） 打開 **Code execution and file creation**（程式碼執行與檔案建立）
3. 不需要 MCP，不需要終端機，不需要安裝任何軟體

## 安裝（一次就好）
1. 下載 [`tw-koubo-cut.zip`](./tw-koubo-cut.zip)
2. Claude：Settings → Capabilities → Skills → **Upload skill**，選這個 zip
3. 確認清單裡出現 `tw-koubo-cut`，開關是開的

## 使用
新開對話，附上直式口播影片（30 到 60 秒最佳），輸入：

```
剪這支。
```

進階（沒有的行刪掉）：

```
剪這支。
標題：第一行「____」，第二行「____」
強調字顏色：#FFD84A
專有名詞：Claude、____、____
不要配樂
```

也可以說「不要標題」、「先給我逐字稿確認再剪」，或附上自己有版權的音樂檔。

收到成品後，**Claude 聽不到聲音**，請用手機開聲音看、逐句核對字幕錯字，並用時間碼回覆修改，例如：

```
0:03 字卡太早，延後半秒
0:12 字幕「克勞德」改成「Claude」
```

## 流程：誰做什麼
你只要做第 1 到 3 步，其餘由 Claude 在雲端完成。

| 步驟 | 誰 | 做什麼 |
| --- | --- | --- |
| 1 | 你 | Settings → Capabilities，打開 Code execution and file creation |
| 2 | 你 | Skills → Upload skill，選 `tw-koubo-cut.zip`，確認開關是開的 |
| 3 | 你 | 新開對話，附上口播影片，輸入「剪這支」 |
| 4 | Claude | 安裝剪輯環境（約 1 分鐘）、檢查規格、找臉、做中文逐字稿（約 25 秒） |
| 5 | Claude | 剪掉重講和停頓、降噪、寫字幕並改正辨識誤字、決定標題 |
| 6 | Claude | 合成配樂和音效、渲染、響度標準化、看接觸表自我檢查 |
| 7 | Claude | 送出 mp4 和 srt，列出剪掉哪些、不確定的判斷、改過的字，附上完整字幕全文 |
| 8 | 你 | 手機開聲音看成品，逐句核對字幕，哪裡不對用時間碼回覆 |
| 9 | Claude | 依時間碼改設定重跑，送出新版，只說改了哪些地方 |
| 10 | 你 | 發布前在平台預覽，確認字幕沒被介面蓋住 |

## 原片與拍攝建議
- 直式 9:16、30 fps、一般 SDR 色彩，單人口播、臉在畫面中、手機架穩。HDR、橫式、非 30 fps 的影片，建議先轉成直式 30 fps 再丟給 Claude。
- 講錯就停一下，重講同一句就好。同一句話在 12 秒內重複出現，Claude 只留最後一次完整的。
- 開頭和結尾各多留半秒。
- 頭頂上方留一點空間，標題會放在那裡。
- 環境太吵會影響辨識，降噪有幫助但有限。

## 常見問題
- **字幕錯字很多**：在請求裡附上專有名詞、人名的正確寫法，或說「先給我逐字稿確認再剪」。
- **呼吸聲沒剪乾淨，或句首輕聲字被切掉**：直接告訴 Claude，它會調整剪輯靈敏度後重跑。
- **字幕在亮背景或白衣服上看不清**：請 Claude 把字幕描邊色調深。
- **影片較長、渲染很久**：渲染時間約為成品長度的 3 倍，長片 Claude 會放到背景執行，請耐心等。

## 預設規格
1080x1920、30 fps、AAC 48k、-14 LUFS。字幕為思源黑體 Bold（Noto Sans CJK TC Bold），白字、深色描邊、強調字黃色 #FFD84A，字幕中心位置 y=1405。

## 使用的開源工具
這些都由 Claude 在雲端自己調用，你不用安裝；模型和字型在執行時下載。

- ffmpeg：切片、混音、響度標準化、輸出 mp4
- SenseVoice（經由 sherpa-onnx）：中文語音辨識
- Silero VAD：判斷哪裡有人說話
- DPDFNet：降噪
- OpenCC：辨識結果轉繁體
- OpenCV：臉部偵測
- Python（numpy、Pillow 等）：逐格渲染字幕與動畫
- Noto Sans CJK TC（思源黑體）：字幕字型
